<h2>Quick Start</h2>

<h3>Development mode</h3>

<blockquote style="padding-top:5px; padding-bottom: 5px">

1. In the terminal, navigate to the project's root folder

2. Execute the following command:

```bash
npm run dev
```

3. The application will run the development server on [http://localhost:3000/](http://localhost:3000/)
</blockquote>

<br />

<h3>Production mode</h3>

<blockquote style="padding-top:5px; padding-bottom: 5px">

1. In the terminal, navigate to the project's root folder

2. Execute the following command:

```bash
npm run build
```

3. Once done, execute the following command:

```bash
npm start
```

4. If the port 3000 is available, the production build will be served on [http://localhost:3000](http://localhost:3000)
</blockquote>

<h2>Technological Overview</h2>

<blockquote>Although my original site was created in 2017, this version is a ground-up rebuild on Next.js (App Router) with React and Typescript, replacing the previous React + Material UI client / Express server split with a single unified application. Styling moved from Material UI + Emotion to Tailwind CSS and DaisyUI, and the standalone Express API was replaced by native Next.js Server Actions. All related assets have also been optimized, which has resulted in a more pleasant UX and boosted overall performance.
</blockquote>
